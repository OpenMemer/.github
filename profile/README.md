# OpenMemer

**Free, open-source meme creation. No watermarks, no nonsense.**

OpenMemer is a collection of lightweight, open-source tools for creating, discovering, and sharing memes.

Our goal is to make meme creation accessible, fast, and self-hostable.

## Our projects

| Project | Description | Status |
|---|---|---|
| [OpenMemer Web](https://github.com/OpenMemer/OpenMemer-Web) | Browser-based meme editor supporting images, GIFs, and customizable text layers. | Available |
| [OpenMemer Index](https://github.com/OpenMemer/OpenMemer-index) | Community-driven meme template collection. | In development |
| [OpenMemer Arbiter](https://github.com/OpenMemer/OpenMemer-arbiter) | Moderation and veto system for Index. | Planned |

## Get started

Try OpenMemer at **https://openmemer.com**.

Want to self-host it? Check out the Docker instructions in the [OpenMemer Web repository](https://github.com/OpenMemer/OpenMemer-Web).

## Open source, for everyone.

OpenMemer is built around the idea that creative tools should be free, accessible, and open to modification.

Contributions, feedback, and suggestions are welcome.
